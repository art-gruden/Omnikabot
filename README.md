# Telegram-бот «Енергозавантаження»: листівки, пости й привітання

Надсилаєте боту текст — отримуєте готову листівку або оформлений пост. Є чотири рубрики: привітання з днем народження, ранкове завантаження, ранкове привітання центру «Омніка» і налаштування на день «Єдність сердець». Бот оформлює текст у стилі ваших попередніх постів, складає промт і малює картинку через ChatGPT (OpenAI API). Типовий заголовок листівки — **ЕНЕРГОЗАВАНТАЖЕННЯ**, типовий розмір — **1280×782**. Усе налаштовується в меню бота; нові шаблони додаються фотографією прямо в чаті. Працює в Docker.

```
Telegram ⇄ bot (python-telegram-bot, long polling) ──► textcard (Pillow) ──► фото / файл
                     │                                 └── OpenAI API: текст постів, промти, зображення
                     ├── /data: bot.sqlite3 (налаштування, зразки, чернетки) + templates/ (фото-шаблони)
                     └── /data/photos: фото на кожен день — 1611.jpg, 1711.jpg…
```

## Встановлення на Ubuntu одним скриптом

На чистому сервері (Ubuntu 22.04 / 24.04 / 26.04 або Debian 12+):

```bash
git clone <адреса цього репозиторію> omnikabot && cd omnikabot
./deploy.sh
```

Скрипт сам: перевірить систему, встановить Docker і плагін compose з офіційного репозиторію та додасть його в автозапуск, за потреби створить файл підкачки (на серверах із 1 ГБ пам'яті без нього збірка обривається), запитає токен бота, ID адміністратора й (необов'язково) ключ OpenAI, запише їх у `.env` з правами 600, створить папку `photos` з правами для бота, збере образ, запустить контейнер і дочекається рядка «бот @… запущено».

Без запитань — усе аргументами:

```bash
./deploy.sh --token 123456789:AAE… --admins 123456 --openai sk-… --yes
```

Токен беруть у Telegram у [@BotFather](https://t.me/BotFather) (`/newbot`), свій ID — командою `/id` у боті. Якщо `ADMIN_IDS` лишити порожнім, адміністратором стане перший, хто напише боту.

Далі напишіть боту `/start`. Ключ ChatGPT можна ввести й пізніше, у меню: `/menu` → 🛠 Адміністрування → 🤖 OpenAI. Без ключа бот теж працює — оформлює тексти простими засобами й не малює картинок.

Порти відкривати не треба: бот сам опитує Telegram (long polling), вхідних з'єднань не приймає.

### Команди deploy.sh

| Команда | |
|---|---|
| `./deploy.sh` | повне встановлення (повторний запуск безпечний) |
| `./deploy.sh update` | `git pull` + перезбірка; налаштування, зразки й шаблони зберігаються |
| `./deploy.sh doctor` | перевірка: Docker, `.env`, токен, права на папку фото, фото на сьогодні, контейнер, помилки в логах |
| `./deploy.sh logs` / `status` / `restart` / `stop` / `start` | повсякденне керування |
| `./deploy.sh token` / `admins` / `openai` / `tz` | змінити значення в `.env` і перезапустити |
| `./deploy.sh backup [тека]` | копія бази з налаштуваннями, зразками й шаблонами (типово в `backups/`, зберігаються 10 останніх) |
| `./deploy.sh restore ФАЙЛ` | відновити з копії |
| `./deploy.sh autobackup on` | щоденна копія о 04:30 через systemd timer (`off` вимикає) |
| `./deploy.sh uninstall` | зупинити й видалити контейнер; дані в томі лишаються |

### Вручну, без скрипта

```bash
cp .env.example .env          # впишіть BOT_TOKEN=... і TZ
mkdir -p photos && sudo chown -R 10001:10001 photos
docker compose up -d --build
docker compose logs -f
```

Часовий пояс (`TZ` у `.env`, типово `Europe/Berlin`) важливий: за ним бот визначає, яке фото вважати сьогоднішнім.

## Структура репозиторію

```
bot/          бот: меню й потоки (main.py), рубрики та ChatGPT (posts.py),
              промти й форматування (content.py), клієнт OpenAI, SQLite
textcard/     рендер листівок на Pillow (render.py), сховище шаблонів, генератор фонів
templates/    8 вбудованих шаблонів: background.jpg + template.json

tests/        тести + імітації Telegram Bot API та OpenAI API
deploy.sh     встановлення й керування на Ubuntu
ci/           готовий workflow для GitHub Actions
Dockerfile, docker-compose.yml, .env.example
```

## Рубрики (`/post`)

| Рубрика | Команда | Що робить |
|---|---|---|
| 🎂 День народження | `/birthday` | з імені та кількох слів про людину складає привітання (або оформлює ваше), робить листівку, генерує промт і картинку |
| 🌅 Ранкове завантаження | `/morning` | оформлює текст-афірмацію й малює листівку; фон можна згенерувати через ChatGPT |
| ☀️ Ранкове привітання «Омніка» | `/omnika` | форматує текст у пост: абзаци, емодзі, хештеги |
| 💗 Єдність сердець | `/unity` | форматує текст налаштування на день і додає фото на сьогодні з папки `ddmm.jpg`; пропонує згенерувати нову картинку |

Текст можна передати одразу командою: `/omnika доброго ранку друзі…`.

**Кнопки під готовим постом або листівкою:**

- 🔄 **Інший варіант** — переоформити той самий вихідний текст наново;
- 📋 **Мій текст** — показати те, що ви надсилали;
- 🎨 **Промт картинки** — бот складає англійський промт для генератора; його можна змінити (✏️) або попросити інший (🔁);
- 🖌 **Згенерувати картинку** — малює зображення через OpenAI. Для листівок картинка стає **новим фоном** і текст одразу лягає на неї; для постів приходить окремою ілюстрацією;
- ✂️ **Скоротити текст** (для листівок) — якщо привітання не вміщається;
- 🖼 **Зробити листівку** (для постів) — той самий текст на фоні шаблону;
- 📅 **Фото дня** (для «Єдності сердець») — надіслати фото на сьогодні, бот збереже його як `ddmm.jpg`;
- 💾 **У зразки стилю** — зберегти вдалий пост як приклад для майбутніх.

### Стиль за попередніми постами

У меню рубрики є «🧩 Зразки стилю». Надішліть або перешліть у бота кілька своїх попередніх постів цієї рубрики — бот збереже їх, попросить ChatGPT описати ваш стиль (тон, довжина, структура, емодзі, типові звороти) і далі оформлятиме нові тексти так само. Опис стилю й три найсвіжіші зразки йдуть у кожен запит. Пости, які бот оформив сам, автоматично поповнюють зразки. Зразки можна видаляти поштучно або очистити всі, а опис стилю — перебудувати кнопкою.

### Фото на кожен день

Для «Єдності сердець» бот шукає фото на сьогодні в папці `photos` (у контейнері `/data/photos`). Назва файлу — день і місяць: `1611.jpg` = 16 листопада. Підходять `.jpg`, `.jpeg`, `.png`, `.webp`; також розпізнаються `16-11.jpg`, `16.11.jpg`, `2026-11-16.jpg`. Якщо фото немає, бот скаже про це й запропонує надіслати його (кнопка «📅 Фото дня», зберігає як `ddmm.jpg`) або згенерувати картинку.

### Налаштування рубрик

`/menu` → 📝 Пости → ⚙️ Налаштування рубрик. Для кожної рубрики: шаблон листівки, заголовок (для листівок), хештеги (для постів), зразки стилю і «💬 Побажання до оформлення» — довільна фраза, яку бот додає до кожного запиту («коротше, без води», «без емодзі», «звертання на ти»).

## Налаштування OpenAI

`/menu` → 🛠 Адміністрування → 🤖 OpenAI (лише для адмінів):

| Пункт | |
|---|---|
| 🔑 Ключ API | повідомлення з ключем бот одразу видаляє з чату, далі показує лише маску `sk-abc…wxyz` |
| 💬 Модель тексту | типово `gpt-5.4-mini`; «🔄 Оновити список з OpenAI» підтягує моделі, доступні вашому ключу; можна вписати назву вручну |
| 🖼 Модель зображень | типово `gpt-image-1.5` |
| ✨ Якість | низька / середня / висока / автоматично — вища дорожча й повільніша |
| 📊 Ліміт | скільки зображень на добу дозволено одній людині (типово 20, `0` — без ліміту) |
| 🌐 Адреса API | для сумісних API або проксі |
| ✅ Перевірити ключ | показує, скільки моделей доступно |

Генерація оплачується з вашого рахунку OpenAI. Розмір зображення бот вибирає під формат листівки (1536×1024, 1024×1536 або 1024×1024) і обрізає під потрібний. У промті завжди вимагається **зображення без тексту й написів** — текст наносить сам бот, і кирилицю генератори пишуть із помилками.

## Листівки без рубрик

Будь-який текст без команди — звичайна листівка з поточного шаблону. `*слово*` виділяє слово акцентним кольором; перший рядок, що починається з `#`, стає разовим заголовком; фото, надіслане боту, стає новим шаблоном (назва → стиль тексту → обробка фону). Під листівкою — кнопки: інший шаблон, вибрати, розмір, файлом, а якщо підключений ChatGPT — «🎨 Новий фон через ChatGPT».

Меню `/menu`: шаблон, заголовок, підпис, розмір (1280×782 типово, 16:9, квадрат, пост 4:5, сторіс або свій), шрифт, колір, світіння, як надсилати (фото / файл PNG чи JPEG / обидва), пости, шаблони, скидання. Адміністрування: доступ до бота, хто додає шаблони, користувачі, дозвіл за ID, свої налаштування як типові.

Команди: `/menu`, `/post`, `/birthday`, `/morning`, `/omnika`, `/unity`, `/templates`, `/title`, `/help`, `/cancel`, `/id`, `/start`.

## `.env`

| Змінна | За замовч. | |
|---|---|---|
| `BOT_TOKEN` | — | обов'язково |
| `ADMIN_IDS` | порожньо | ID адмінів через кому; порожньо — адміном стає перший користувач |
| `OPENAI_API_KEY` | порожньо | можна не задавати й ввести ключ у меню бота |
| `OPENAI_TEXT_MODEL` / `OPENAI_IMAGE_MODEL` | `gpt-5.4-mini` / `gpt-image-1.5` | стартові моделі |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | сумісний API або проксі |
| `IMAGE_LIMIT_PER_DAY` | 20 | ліміт генерацій на людину на добу |
| `PHOTOS_DIR` | `/data/photos` | папка з фото `ddmm.jpg` |
| `DEFAULT_TITLE` / `DEFAULT_SIZE` / `DEFAULT_TEMPLATE` | `ЕНЕРГОЗАВАНТАЖЕННЯ` / `1280x782` / `pink_glow` | стартові значення |
| `MAX_WORDS` / `MAX_CHARS` / `MAX_POST_CHARS` | 40 / 400 / 3000 | ліміти тексту листівки й поста |
| `MAX_UPLOAD_MB` | 20 | ліміт фото (Bot API більше ботам не віддає) |
| `RENDER_CONCURRENCY` | 2 | одночасних рендерів |
| `LOG_LEVEL` | `INFO` | у лог ідуть лише ID і дії — без текстів, ключа й токена |

## Що перевірено, а що ні

**Перевірено в пісочниці (Python 3.13, python-telegram-bot 22.8, Pillow 12.3, httpx 0.28):** усі три набори тестів. Зокрема: оформлення всіх чотирьох рубрик із ключем і без нього; що в запит до GPT справді йдуть опис стилю й зразки; складання промта й генерація зображення (параметри запиту, заборона тексту на картинці, розмір під формат); фон від ChatGPT стає шаблоном і листівка перемальовується; фото дня — і знайдене в папці, і надіслане в бот; скорочення задовгого привітання; зрозумілі повідомлення при 429 і 401; денний ліміт генерацій; ключ видаляється з чату й не потрапляє в логи; права звичайного користувача; усе переживає перезапуск. Також перевірено справжню точку входу `python -m bot.main` з ключем у змінних оточення і `deploy.sh` на підставному `docker`: встановлення, повторний запуск, `doctor`, `update`, `backup`, зміна токена, ID адмінів і часового поясу, відмова на неправильний токен, робота без терміналу.

**Не перевірено:** справжнє встановлення на Ubuntu-сервері (у пісочниці немає доступу до репозиторіїв Docker), справжній Telegram і справжній OpenAI (api.telegram.org і api.openai.com із пісочниці недоступні), збірка Docker-образу (Docker Hub недоступний). Назви моделей змінюються: якщо `gpt-5.4-mini` або `gpt-image-1.5` вашому ключу недоступні, бот покаже помилку OpenAI — натисніть «🔄 Оновити список з OpenAI» і виберіть наявну модель.

## Обмеження

- Лише приватні чати; у групах бот мовчить.
- Емодзі не малюються на листівках (у шрифтах їх немає): бот пропускає їх і пише про це в підписі.
- Текст листівки — до 40 слів (найкраще 10–20), тексти постів — до 3000 символів; довгий пост Telegram розбиває на кілька повідомлень.
- Кнопки працюють для останніх 200 листівок і 50 чернеток кожного користувача.
- Один процес і SQLite: для кількох десятків активних користувачів цього досить. Рендер ≈0,1–0,3 с, генерація зображення — десятки секунд, за цей час бот пише «🖌 Малюю…».
- Бот ніколи не публікує нічого сам: він віддає вам готовий текст і картинку, а ви копіюєте їх у свій канал.
