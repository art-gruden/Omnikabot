# Telegram-бот «Енергозавантаження»: листівки, пости й привітання

Надсилаєте боту текст — отримуєте готову листівку або оформлений пост. Є чотири рубрики: привітання з днем народження, ранкове завантаження, ранкове привітання центру «Омніка» і налаштування на день «Єдність сердець». Тексти оформлюються простими засобами або моделлю, а картинки малює Gemini (Nano Banana 2). Провайдери тексту й зображень вибираються в `.env`: типово обидва Gemini, OpenAI лишається як запасний варіант. Той самий промт одним натисканням відкривається в браузері з ChatGPT або копіюється в буфер. Типовий заголовок листівки — **ЕНЕРГОЗАВАНТАЖЕННЯ**, типовий розмір — **1280×782**. Усе налаштовується в меню бота; нові шаблони додаються фотографією прямо в чаті. Працює в Docker.

```
Telegram ⇄ bot (python-telegram-bot, long polling) ──► textcard (Pillow) ──► фото / файл
                     │                                 ├── тексти: Gemini API або OpenAI API (TEXT_PROVIDER)
                     │                                 └── зображення: Gemini API або OpenAI API (IMAGE_PROVIDER)
                     ├── /data: bot.sqlite3 (налаштування, зразки, чернетки) + templates/ (фото-шаблони)
                     └── /data/photos: фото на кожен день — 1611.jpg, 1711.jpg…
```

## Встановлення на Ubuntu одним скриптом

На чистому сервері (Ubuntu 22.04 / 24.04 / 26.04 або Debian 12+):

```bash
git clone <адреса цього репозиторію> omnikabot && cd omnikabot
./deploy.sh
```

Скрипт сам: перевірить систему, встановить Docker і плагін compose з офіційного репозиторію та додасть його в автозапуск, за потреби створить файл підкачки (на серверах із 1 ГБ пам'яті без нього збірка обривається), запитає токен бота, ID адміністратора й (необов'язково) ключі OpenAI та Gemini, запише їх у `.env` з правами 600, створить папку `photos` з правами для бота, збере образ, запустить контейнер і дочекається рядка «бот @… запущено».

Без запитань — усе аргументами:

```bash
./deploy.sh --token 123456789:AAE… --admins 123456 --openai sk-… --gemini AIza… --yes
```

Токен беруть у Telegram у [@BotFather](https://t.me/BotFather) (`/newbot`), свій ID — командою `/id` у боті. Якщо `ADMIN_IDS` лишити порожнім, адміністратором стане перший, хто напише боту.

Далі напишіть боту `/start`. Ключ ChatGPT можна ввести й пізніше, у меню: `/menu` → 🛠 Адміністрування → 🤖 OpenAI. Без ключа бот теж працює — оформлює тексти простими засобами й не малює картинок.

Порти відкривати не треба: бот сам опитує Telegram (long polling), вхідних з'єднань не приймає.

### Команди deploy.sh

| Команда | |
|---|---|
| `./deploy.sh` | повне встановлення (повторний запуск безпечний) |
| `./deploy.sh update` | `git pull` + перезбірка; налаштування, зразки й шаблони зберігаються |
| `./deploy.sh doctor` | перевірка: Docker, `.env`, токен, права на папку фото, фото на сьогодні, контейнер, помилки в логах |
| `./deploy.sh logs` / `status` / `restart` / `stop` / `start` | повсякденне керування |
| `./deploy.sh token` / `admins` / `openai` / `tz` | змінити значення в `.env` і перезапустити |
| `./deploy.sh gemini` | задати ключ Gemini й перемкнути малювання картинок на Gemini |
| `./deploy.sh provider gemini\|openai` | перемкнути провайдера зображень (`IMAGE_PROVIDER`) |
| `./deploy.sh backup [тека]` | копія бази з налаштуваннями, зразками й шаблонами (типово в `backups/`, зберігаються 10 останніх) |
| `./deploy.sh restore ФАЙЛ` | відновити з копії |
| `./deploy.sh autobackup on` | щоденна копія о 04:30 через systemd timer (`off` вимикає) |
| `./deploy.sh uninstall` | зупинити й видалити контейнер; дані в томі лишаються |

### Вручну, без скрипта

```bash
cp .env.example .env          # впишіть BOT_TOKEN=..., TZ і GEMINI_API_KEY=... (або IMAGE_PROVIDER=openai)
mkdir -p photos && sudo chown -R 10001:10001 photos
docker compose up -d --build
docker compose logs -f
```

Часовий пояс (`TZ` у `.env`, типово `Europe/Berlin`) важливий: за ним бот визначає, яке фото вважати сьогоднішнім.

## Структура репозиторію

```
bot/          бот: меню й потоки (main.py), рубрики та ChatGPT (posts.py),
              промти й форматування (content.py), готові промти картинок і посилання
              на ChatGPT (image_prompts.py), провайдери тексту (text_gen.py) і зображень
              (image_gen.py), спільний клієнт Gemini (gemini_api.py), адаптер промту для Gemini
              (gemini_prompt.py), клієнт OpenAI, SQLite

templates/    8 вбудованих шаблонів: background.jpg + template.json
prompts/      готові промти картинок: 8 категорій по 3 варіанти + день народження

tests/        тести + імітації Telegram Bot API та OpenAI API
deploy.sh     встановлення й керування на Ubuntu
ci/           готовий workflow для GitHub Actions
Dockerfile, docker-compose.yml, .env.example
```

## Рубрики (`/post`)

| Рубрика | Команда | Що робить |
|---|---|---|
| 🎂 День народження | `/birthday` | з імені та кількох слів про людину **складає** привітання моделлю (або оформлює ваше локально), малює листівку внутрішнім рендером; кнопка віддає картинку з привітанням у Gemini |
| 🌅 Ранкове завантаження | `/morning` | оформлює текст-афірмацію **локально** й малює листівку **внутрішнім рендером**; окрема кнопка віддає всю картинку разом із текстом у Gemini |
| ☀️ Ранкове привітання «Омніка» | `/omnika` | форматує текст **простими засобами** (абзаци, емодзі, хештеги); кнопка «Оформити з Gemini» — якщо цього мало; у картинці Gemini домальовує **сьогоднішню дату** |
| 💗 Єдність сердець | `/unity` | форматує текст налаштування на день, **складає промт картинки за цим текстом** (послання й настрій дня) і одразу малює її; фото на сьогодні `ddmm.jpg` лишається запасним варіантом |

Текст можна передати одразу командою: `/omnika доброго ранку друзі…`.

### Як працює кожна рубрика

**☀️ Омніка.** Текст оформлюється локально: типографіка, абзаци, емодзі на початку абзаців, хештеги — без звернення до моделі. Якщо цього замало, кнопка **✨ Оформити з Gemini** переписує текст у вашому стилі (за зразками рубрики) і виділяє **жирним** головне послання. Кольору тексту в повідомленнях Telegram немає — колір може нести лише картинка.

У промт картинки додається сьогоднішня дата, яку модель малює просто в кадрі («17 листопада»). Розмір, шрифт і колір напису міняються щодня — набори різної довжини, тож пара «розмір + колір» не повторюється понад місяць. Перше натискання «🖌 Згенерувати картинку» малює за готовим промтом рубрики; **друге й дальші спершу просять Gemini оновити промт** за текстом посту (нова сцена, те саме послання) і лише тоді малюють. Якщо промт ви вписали самі, модель його не переписує. Після генерації бот надсилає картинку разом із оформленим текстом посту — готове до публікації.

**🌅 Ранкове завантаження і 🎂 День народження.** Обидві листівки малюються внутрішнім рендером (Pillow): фон із шаблону, текст наносить код, кирилиця завжди правильна. Текст оформлюється локально — до моделі по оформлення бот не звертається взагалі. Виняток один: для дня народження модель **складає** привітання з ваших кількох слів (кнопка «Скласти привітання» і далі «✍️ Інший текст»).

Кнопка **🔄 Інший варіант** під листівкою перемикає на наступний шаблон — міняється і фонове зображення, і стиль (шрифти, кольори, світіння), бо кожен шаблон несе власне оформлення. Жодних запитів до моделі при цьому немає.

Кнопка **🎨 Картинка з текстом у Gemini** — єдине місце, де модель малює текст: вона отримує заголовок і текст листівки з вимогою зробити напис головним елементом кадру (блок тексту займає 70–80% кадру, сцена позаду — тиха й малоконтрастна). Кнопка **🖌 Згенерувати картинку** працює як раніше: малює тільки фон, а текст на нього наносить бот.

**💗 Єдність сердець.** Отримавши текст, бот просить Gemini визначити послання й настрій дня і скласти за ними промт картинки, одразу малює її й показує картинку разом із оформленим текстом. Вимкнути автоматичне малювання: `AUTO_IMAGE=0`. Якщо генерація не вдалася, лишається фото на сьогодні `ddmm.jpg`.

**Кнопки під готовим постом або листівкою:**

- ✨ **Оформити з Gemini** (пости) — переписати текст моделлю й виділити головне жирним;
- 🎨 **Картинка з текстом у Gemini** (листівки) — модель малює картинку разом із текстом усередині;
- 🔄 **Інший варіант** — для постів переоформити текст наново, для листівок — наступний шаблон: інший фон і стиль;
- ✍️ **Інший текст** (день народження) — скласти інше привітання;
- 📋 **Мій текст** — показати те, що ви надсилали;
- 🎨 **Промт картинки** — бот бере готовий промт для цієї рубрики, підставляє дату, сезон і тему посту й показує його з кнопками (див. «Готові промти картинок»);
- 🖌 **Згенерувати картинку** — малює зображення через вибраного провайдера (Gemini або OpenAI). Для листівок картинка стає **новим фоном** і текст одразу лягає на неї; для постів приходить окремою ілюстрацією;
- ✂️ **Скоротити текст** (для листівок) — якщо привітання не вміщається;
- 🖼 **Зробити листівку** (для постів) — той самий текст на фоні шаблону;
- 📅 **Фото дня** (для «Єдності сердець») — надіслати фото на сьогодні, бот збереже його як `ddmm.jpg`;
- 💾 **У зразки стилю** — зберегти вдалий пост як приклад для майбутніх.

### Готові промти картинок

Промти лежать у `prompts/`: 24 основні (8 категорій по 3 варіанти) і 3 для дня народження. Кожна рубрика бере свої категорії:

| Рубрика | Категорії промтів |
|---|---|
| 🎂 День народження | `birthday` (слово «ювілей» у тексті дає ювілейний фон) |
| 🌅 Ранкове завантаження, «Новий фон» під звичайною листівкою | `affirmation` — порожній фон картки |
| ☀️ Ранкове привітання «Омніка» | `calendar`, `daily_energy`, `nature`, `cozy` |
| 💗 Єдність сердець | `heart`, `intention` |

Дату, день тижня, сезон, рослини й палітру підставляє код. Тему дня (`DAY_THEME`) і символ бот питає в GPT одним коротким запитом за текстом посту; без ключа OpenAI береться типова тема категорії. Видається той промт рубрики, який найдовше не використовувався, а сюжети чотирьох останніх ідуть у промт як «уникати», тож картинки не повторюються.

**Кнопки під промтом:**

- 🌐 **Відкрити в ChatGPT** — посилання `https://chatgpt.com/?q=…`: браузер відкриває ChatGPT із промтом у полі введення. Працює й без ключа OpenAI.
- 📋 **Скопіювати промт** — бот надсилає промт окремим повідомленням моноширинним блоком; натискання на текст копіює його в буфер. (Вбудована кнопка копіювання Telegram вміщує лише 256 символів, а промт має близько 1 500.)
- 🖌 **Згенерувати картинку** — намалювати цей промт прямо в боті через Gemini або OpenAI (потрібен ключ провайдера).
- 🔁 **Інший промт** — наступний варіант із категорій рубрики; ✏️ **Змінити промт** — вписати свій.

Посилання виходить на 2 000–2 400 символів, а Telegram не публікує максимальну довжину URL у кнопці. Тому бот спершу пробує повне посилання; якщо Telegram його відхиляє, надсилає коротше (до `SAFE_BUTTON_URL`, без кількох необов'язкових речень) і запам'ятовує цей поріг; якщо не проходить і воно — лишає тільки копіювання. Кнопка копіювання завжди дає повний текст.

Як змінювати й додавати промти, описано в `prompts/README.md`. Якщо файлів промтів немає або вони пошкоджені, бот складає промт по-старому, через GPT.

### Стиль за попередніми постами

У меню рубрики є «🧩 Зразки стилю». Надішліть або перешліть у бота кілька своїх попередніх постів цієї рубрики — бот збереже їх, попросить ChatGPT описати ваш стиль (тон, довжина, структура, емодзі, типові звороти) і далі оформлятиме нові тексти так само. Опис стилю й три найсвіжіші зразки йдуть у кожен запит. Пости, які бот оформив сам, автоматично поповнюють зразки. Зразки можна видаляти поштучно або очистити всі, а опис стилю — перебудувати кнопкою.

### Фото на кожен день

Для «Єдності сердець» бот шукає фото на сьогодні в папці `photos` (у контейнері `/data/photos`). Назва файлу — день і місяць: `1611.jpg` = 16 листопада. Підходять `.jpg`, `.jpeg`, `.png`, `.webp`; також розпізнаються `16-11.jpg`, `16.11.jpg`, `2026-11-16.jpg`. Якщо фото немає, бот скаже про це й запропонує надіслати його (кнопка «📅 Фото дня», зберігає як `ddmm.jpg`) або згенерувати картинку.

### Налаштування рубрик

`/menu` → 📝 Пости → ⚙️ Налаштування рубрик. Для кожної рубрики: шаблон листівки, заголовок (для листівок), хештеги (для постів), зразки стилю і «💬 Побажання до оформлення» — довільна фраза, яку бот додає до кожного запиту («коротше, без води», «без емодзі», «звертання на ти»).

## Gemini: тексти й зображення

Бот звертається до Gemini двічі різними шляхами: текстова модель оформлює пости, складає промти й описує стиль, а модель зображень їх малює. Обидва провайдери перемикаються незалежно, OpenAI лишається сумісним варіантом.

| Що робить | Змінна | Типово | Модель |
|---|---|---|---|
| оформлення текстів, промти, опис стилю | `TEXT_PROVIDER` | `gemini` | `GEMINI_TEXT_MODEL=gemini-3.5-flash` |
| малювання картинок | `IMAGE_PROVIDER` | `gemini` | `GEMINI_MODEL=nano-banana-2-1k` |

### Як перемкнути провайдера

У `.env`:

```bash
TEXT_PROVIDER=gemini             # або openai
IMAGE_PROVIDER=gemini            # або openai
GEMINI_API_KEY=AIza...           # aistudio.google.com → Get API key
GEMINI_TEXT_MODEL=gemini-3.5-flash
GEMINI_MODEL=nano-banana-2-1k    # Nano Banana 2, розмір 1K
```

Потім `docker compose up -d` (або `./deploy.sh restart`). Те саме однією командою: `./deploy.sh gemini` (запитає ключ і поставить обидва провайдери на Gemini), назад — `./deploy.sh provider openai`. Якщо змінні не задано, бот бере Gemini, коли є `GEMINI_API_KEY`, інакше OpenAI, тож старі встановлення працюють без змін. Поточні провайдери й моделі видно в боті: `/menu` → 🛠 Адміністрування.

Текстові запити йдуть на `…/v1beta/models/<модель>:generateContent` із `systemInstruction` і `contents`; `GEMINI_API=interactions` перемикає й текст, і зображення на новіший інтерфейс Gemini API. Для моделей Gemini 3 бот не нав\'язує глибину «роздумів» — її задає `GEMINI_THINKING=low|medium|high`, — але завжди просить запас вихідних токенів, щоб відповідь не обірвалася.

`GEMINI_MODEL` приймає назву-псевдонім або справжній ID моделі. Суфікс `-1k`, `-2k`, `-4k` задає розмір (`imageSize`):

| Значення | Модель у Gemini API |
|---|---|
| `nano-banana-2-1k` | `gemini-3.1-flash-image`, 1K |
| `nano-banana-2.1-1k` | `gemini-nano-banana-2.1`, 1K |
| `nano-banana-2-lite-1k` | `gemini-3.1-flash-lite-image`, 1K |
| `nano-banana-pro-2k` | `gemini-3-pro-image`, 2K |
| `gemini-…` | будь-який ID як є; розмір із `GEMINI_IMAGE_SIZE` (типово 1K) |

Запит іде на `…/v1beta/models/<модель>:generateContent` із `responseModalities: ["IMAGE"]` та `imageConfig: {aspectRatio, imageSize}`; ключ передається в заголовку `x-goog-api-key`. Співвідношення сторін бот вибирає найближче до потрібного: для постів і типової листівки 1280×782 це 16:9. `GEMINI_API=interactions` перемикає на новіший інтерфейс Gemini API (`/v1beta/interactions`).

### Що додається до промту для Gemini

Готовий промт рубрики лишається тим самим (його ж відкриває кнопка «Відкрити в ChatGPT»), а перед відправленням у Gemini його обробляє адаптер `bot/gemini_prompt.py`:

1. прибирає те, що модель могла б надрукувати на картинці ненавмисно: написи в лапках, день тижня, дату цифрами (`2026-11-17` стає `mid-November`);
2. додає загальний блок вимог: нова композиція щоразу, сезон за датою, спокійні верхні 20–25% кадру під напис, жодного тексту, цифр і логотипів, бажано 16:9;
3. додає вимоги для категорії картинки: календарна картка, затишний ранок, ранкова природа, енергія дня, намір, фон афірмації, особлива дата (а також привітання групи й день народження). Для фонів афірмації та дня народження текст лягає в центр, тому там діє правило «спокійний центр» замість «спокійний верх»;
4. додає сезон на сьогодні, варіацію композиції та сюжети останніх генерацій рубрики, від яких треба відрізнятися;
5. якщо напис у кадрі потрібен (дата для «Омніки», текст листівки для «Ранкового завантаження» й «Дня народження») — додає блок, який скасовує заборону тексту саме для цього напису: модель отримує рядок посимвольно, з вимогою не перекладати, не скорочувати й не додавати нічого іншого. Для листівки напис має бути головним елементом і займати 70–80% кадру, для дати — спокійну верхню зону.

Для OpenAI промт іде без змін, як раніше.

### Повтори, тайм-аути, запасна картинка

- Зображення: до 3 спроб (`IMAGE_ATTEMPTS`), кожна з тайм-аутом `GEMINI_TIMEOUT` (120 с), з паузою між спробами. Тексти: 2 спроби (`TEXT_ATTEMPTS`); якщо модель не відповіла, бот оформлює текст простими засобами й каже про це. Повторюються тайм-аут, 429, 5xx і відповідь без зображення; неправильний ключ, невідома модель і заблокований промт не повторюються.
- Якщо всі спроби невдалі, користувач бачить причину. Для посту бот надсилає запасну картинку: фото дня `ddmm.jpg` з папки фото, а якщо його немає — файл із `IMAGE_BACKUP_DIR`. Якщо запасної немає, пост лишається без нової ілюстрації. Листівка в такому разі лишається на поточному фоні.
- Невдала генерація й запасна картинка не витрачають денний ліміт.
- У лог ідуть провайдер, модель, номер спроби, тривалість, розмір і хеш промту — без тексту промту й без ключа.

### Збережені файли й історія

Кожне згенероване зображення зберігається в `/data/generated/` (`GENERATED_DIR`) з назвою `РРРР-ММ-ДД_рубрика_промт_ГГХХСС.png`; тримаються останні 200 файлів (`GENERATED_IMAGES_KEEP`). Генератор повертає метадані: провайдер, модель, промт (до й після адаптера), шлях до файла, розмір, кількість спроб. Те саме без тексту промту записується в таблицю `image_log` у SQLite. З цієї історії адаптер бере варіацію композиції, якої давно не було, і список останніх сцен, тому повторна генерація того самого промту дає іншу картинку.

У промті завжди вимагається **зображення без тексту й написів** — текст наносить сам бот, і кирилицю генератори пишуть із помилками.

## Листівки без рубрик

Будь-який текст без команди — звичайна листівка з поточного шаблону. `*слово*` виділяє слово акцентним кольором; перший рядок, що починається з `#`, стає разовим заголовком; фото, надіслане боту, стає новим шаблоном (назва → стиль тексту → обробка фону). Під листівкою — кнопки: інший шаблон, вибрати, розмір, файлом, а якщо підключений ChatGPT — «🎨 Новий фон через ChatGPT».

Меню `/menu`: шаблон, заголовок, підпис, розмір (1280×782 типово, 16:9, квадрат, пост 4:5, сторіс або свій), шрифт, колір, світіння, як надсилати (фото / файл PNG чи JPEG / обидва), пости, шаблони, скидання. Адміністрування: доступ до бота, хто додає шаблони, користувачі, дозвіл за ID, свої налаштування як типові.

Команди: `/menu`, `/post`, `/birthday`, `/morning`, `/omnika`, `/unity`, `/templates`, `/title`, `/help`, `/cancel`, `/id`, `/start`.

## Що перевірено, а що ні

**Перевірено в пісочниці (Python 3.13, python-telegram-bot 22.8, Pillow 12.3, httpx 0.28):** усі п'ять наборів тестів. Зокрема: оформлення всіх чотирьох рубрик із ключем і без нього; що в запит до GPT справді йдуть опис стилю й зразки; готовий промт картинки для кожної рубрики з темою посту, кнопки «Відкрити в ChatGPT» і «Скопіювати промт», чергування промтів без повторів, поведінка, коли Telegram відхиляє довге посилання, запасний шлях без файлів промтів; локальне оформлення «Омніки» й кнопка «Оформити з Gemini» з виділенням головного жирним; напис із сьогоднішньою датою в картинці та його щоденний стиль; оновлення промту моделлю при повторній генерації (і збереження промту, вписаного вручну); картинка з текстом усередині для листівки; промт за текстом посту й автоматична картинка для «Єдності сердець»; текстові збої (порожня відповідь, 503, неправильний ключ) і запасне оформлення; генерація зображення через OpenAI (параметри запиту, заборона тексту на картинці, розмір під формат) і через Gemini на імітації його API (модель і параметри запиту, адаптер промту, три спроби, тайм-аут, запасна картинка, історія генерацій, робота без ключа OpenAI); фон від ChatGPT стає шаблоном і листівка перемальовується; фото дня — і знайдене в папці, і надіслане в бот; скорочення задовгого привітання; зрозумілі повідомлення при 429 і 401; денний ліміт генерацій; ключ видаляється з чату й не потрапляє в логи; права звичайного користувача; усе переживає перезапуск. Також перевірено справжню точку входу `python -m bot.main` з ключем у змінних оточення і `deploy.sh` на підставному `docker`: встановлення, повторний запуск, `doctor`, `update`, `backup`, зміна токена, ID адмінів і часового поясу, команди `gemini` і `provider`, відмова на неправильний токен, робота без терміналу.

**Не перевірено зі справжнім Gemini:** як саме модель малює кирилицю в кадрі (дату й текст листівки) — це головне, що варто перевірити першим запуском; поведінка `gemini-3.5-flash` і `gemini-3.1-flash-image` на справжньому ключі; режим `GEMINI_API=interactions` зібрано з документації, без живого запиту.

**Не перевірено:** справжнє встановлення на Ubuntu-сервері (у пісочниці немає доступу до репозиторіїв Docker), справжній Telegram, справжній OpenAI і справжній Gemini (api.telegram.org, api.openai.com і generativelanguage.googleapis.com із пісочниці недоступні; ID моделі `gemini-3.1-flash-image` і формат запиту взято з документації Google станом на листопад 2026), збірка Docker-образу (Docker Hub недоступний). Зі справжнім Telegram і ChatGPT не перевірено й кнопку «Відкрити в ChatGPT»: яку найбільшу довжину посилання приймає Telegram і чи підхоплює ChatGPT параметр `?q=` у вашому браузері чи застосунку, покаже перший запуск (параметр офіційно не описаний; на телефоні посилання може відкрити застосунок, який його не прочитає, і тоді виручає копіювання). Назви моделей змінюються: якщо `gpt-5.4-mini` або `gpt-image-1.5` вашому ключу недоступні, бот покаже помилку OpenAI — натисніть «🔄 Оновити список з OpenAI» і виберіть наявну модель.

## Обмеження

- Лише приватні чати; у групах бот мовчить.
- Емодзі не малюються на листівках (у шрифтах їх немає): бот пропускає їх і пише про це в підписі.
- Текст листівки — до 40 слів (найкраще 10–20), тексти постів — до 3000 символів; довгий пост Telegram розбиває на кілька повідомлень.
- Кнопки працюють для останніх 200 листівок і 50 чернеток кожного користувача.
- Один процес і SQLite: для кількох десятків активних користувачів цього досить. Рендер ≈0,1–0,3 с, генерація зображення — десятки секунд, за цей час бот пише «🖌 Малюю…».
- Бот ніколи не публікує нічого сам: він віддає вам готовий текст і картинку, а ви копіюєте їх у свій канал.
